# SoW Skills

A curated collection of skills used at Shades of Web. Each skill is a self-contained directory with a `SKILL.md` file (plus any supporting references, scripts, or templates) that Claude or any other Agentic IDE and/or can load on demand to bring focused expertise to a task.

## Repository layout

```
skills/
├── design/        # Visual design and UI/UX
├── development/   # Engineering workflows and tooling
├── sow-custom/    # Shades of Web internal standards
└── vercel/        # Vercel engineering best practices
```

## Skills

### design/

| Skill | Purpose |
| --- | --- |
| [canvas-design](design/canvas-design/SKILL.md) | Create original visual art (posters, designs) as `.png` / `.pdf` from a design philosophy. |
| [frontend-design](design/frontend-design/SKILL.md) | Build distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. |
| [ui-ux-pro-max](design/ui-ux-pro-max/SKILL.md) | UI/UX intelligence: 50+ styles, 97 palettes, 57 font pairings, 25 chart types across 9 stacks. |
